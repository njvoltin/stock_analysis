📊 This project automates stock data analysis in Excel using VBA (Visual Basic for Applications).
The script loops through all stocks for each quarter and calculates key performance metrics, providing both summary tables and highlight statistics.

🔑 Features
✅ Base Solution

For each stock in each quarter, the script outputs:

Ticker Symbol

Quarterly Change (from opening price at the beginning of the quarter to closing price at the end)

Percentage Change (relative to the opening price)

Total Stock Volume

🔄 Moderate Solution

In addition to the above, the script identifies:

📈 Greatest % Increase

📉 Greatest % Decrease

📊 Greatest Total Volume

💪 Hard Solution

Enhancements include:

Automating the script to run across all worksheets (quarters) in the workbook in one execution.

Dynamic table formatting for readability.
